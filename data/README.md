## recipes.json
Перенесён из `mefffodiy-n/EVE-PI-app` без изменений содержимого.
69 рецептов: 8×P4, 22×P3, 24×P2, 15×P1. Целостность проверена — все
входы разрешаются в известные продукты или R0-сырьё.

Известная проблема: `Positron Cord` и `Ukomi Superconductors` имеют
идентичный состав входов, а `Positron Cord` отсутствовал в `PI_TYPE_NAMES`
в `main.py` v1 (не имел type_id и цены). Тест
`tests/test_recipes.py::test_no_duplicate_recipes_by_input_signature`
падает намеренно, пока это не разобрано.

## pi_reference.json
Справочник CPU/PG: ёмкость командных центров по уровням Command Center
Upgrades, каталог шаблонов застройки, потребление линков по радиусу
планеты, пропускная способность фабрик, рекомендованные скиллы.

**Источник:** README репозитория https://github.com/DalShooth/EVE_PI_Templates,
раздел "Best Estimate Template PG and CPU Usage". Автор источника называет
числа "best estimate". Внутренняя согласованность проверена: суммы структур
сходятся с заявленными total, остатки — с ёмкостью CC (13 проверок).

Два зафиксированных расхождения — см. поля `_source.known_discrepancy`
и `_source.miner_p1_json_mismatch` внутри файла.

Сами JSON-файлы шаблонов (для импорта в игру) лежат в подпапке
`PlanetaryInteractionTemplates` того репозитория и в наш проект не
копируются: приложению нужны их характеристики (CPU/PG), а не содержимое.
Если понадобится разбирать структуру шаблонов (например, чтобы менять
`"CmdCtrLv"` под уровень персонажа) — файлы надо будет добавить отдельно.

## planet_industry.csv
**Нужно скопировать вручную** из исходного репозитория (`planet industry.csv`,
с пробелом в имени) и положить сюда под именем `planet_industry.csv`.

Почему файла нет в скелете: он на 975 строк, и через просмотр GitHub
доступна только часть — фабриковать недостающие плотности сырья нельзя.

После копирования `domain.planets.load_planets()` применит нормализацию
заголовков (`Polyramids` → `Polyaramids`, `Supertensil Plastics` →
`Supertensile Plastics`) и отфильтрует служебные строки (`max P2`, `#REF`).
