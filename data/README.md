# data/

- `recipes.json` — перенесён из исходного репозитория `mefffodiy-n/EVE-PI-app`
  без изменений содержимого (я сверил файл целиком через GitHub).

- `planet_industry.csv` — **нужно скопировать вручную** из исходного репозитория
  (`planet industry.csv`, с пробелом в имени, в корне `EVE-PI-app`) и положить
  сюда под именем `planet_industry.csv` (без пробела).

  Почему файл не включён в этот скелет: он на 975 строк, и через доступный мне
  просмотр GitHub я получил только часть файла (страница обрезается по объёму) —
  а фабриковать недостающие строки с плотностями сырья я не буду, это как раз
  те данные, которые вы просили брать только из проверенного источника.

  После копирования файла:
  1. переименуйте `planet industry.csv` → `planet_industry.csv`;
  2. запустите `domain.planets.load_planets()` — она сама применит нормализацию
     заголовков (`Polyramids` → `Polyaramids`, `Supertensil Plastics` →
     `Supertensile Plastics`) и отфильтрует служебные строки (`max P2`, `#REF`);
  3. сверьте, что число строк после `_clean_rows()` соответствует ожиданиям
     (в оригинале — 975 строк минус служебная шапка и отфильтрованный мусор).
